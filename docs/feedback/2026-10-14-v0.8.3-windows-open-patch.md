## 남은 한계

- **느림:** 창 앞으로 가져오기가 매번 약 33초. 원인은 PowerShell 시작과 `Add-Type` C# 컴파일(보안 프로그램 검사). 빠르게 하려면 미리 컴파일한 DLL을 쓰거나, 상주 프로세스 하나를 두고 재사용해야 함.
- **이름 중복:** 탭/창 이름으로 찾으므로 두 프로젝트에 같은 역할 이름(`main` 등)이 있으면 먼저 찾은 쪽이 앞으로 옴. 역할 이름에 과제 이름을 붙이면(`fin-main`, `edms-main`) 해결 — `agents.json`만 바꾸면 됨(main 판정은 이름이 아니라 `dir: "."`).
- **창 이름 번호:** `agentsemble-p<번호>`는 `--also` 순서 기준이라 board를 다른 순서로 켜면 번호가 바뀜.
- **탭은 그대로:** 창만 앞으로 오고, 그 안에서 보이는 탭은 바꾸지 않음(요청대로).

## 코드 수정 없이 운영으로 해결한 것

- **board를 Claude 세션 안에서 켜지 말 것** (또는 아래 변수를 지우고 켤 것). Open으로 연 창이 `CLAUDE_CODE_CHILD_SESSION=1` 등을 물려받아 "Transcript saving is off" 상태가 되고, 세션 목록에 등록되지 않아 board·SendMessage에서 안 보임.
  지울 변수: `CLAUDE_CODE_CHILD_SESSION`, `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_CODE_MESSAGING_SOCKET`, `CLAUDE_CODE_MESSAGING_TOKEN`, `CLAUDE_CODE_SESSION_ATTENDED`, `CLAUDE_CODE_SESSION_ID`, `CLAUDE_PID`, `CLAUDECODE`
  (수정 1의 `wt` 경로는 탭을 기존 Windows Terminal 프로세스가 만들기 때문에 이 상속이 덜 일어날 수 있으나, 확인하지 않음)
- **Docker는 주소 통로로만:** 컨테이너 안 board는 Windows 창을 못 열어서(`open.mjs`가 win32 아니면 `unsupported`), 진짜 board는 Windows에서 `--port 8741`로, Docker nginx(`nginx 설정 파일`)가 `127.0.0.1:8740` → `host.docker.internal:8741`로 넘김. `hostOk`/`sameOrigin` 검사 통과를 위해 8740 페이지에서 온 요청만 Host·Origin을 8741로 바꿈.
