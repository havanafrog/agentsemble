# agentsemble 보드 UI 개선 — 플러그인 반영 요청

2026-10-22 · havanafrog

agentsemble 0.8.8 보드(`bin/board.html`, `bin/board.mjs`)에 로컬로 붙여 쓰고 있는 UI 개선 4가지를 다음 플러그인 버전에 반영해 주세요. 보드의 읽기 전용 원칙은 그대로이고, 보드 자체 테스트 184개가 모두 통과합니다.

## 변경 요약

| 기능 | 바뀐 파일 | 저장 위치 | 조작 |
| --- | --- | --- | --- |
| 사이드바 편집(Notion식) | `board.html` | 브라우저 localStorage `as-order`, `as-meta` | 드래그, Alt+↑/↓, ⋯ 메뉴, 우클릭, 더블클릭, F2 |
| 제안 프롬프트 표시 | `board.mjs`, `board.html` + mod `suggest-relay` | `~/.claude/agentsemble-suggest/<세션ID>.json` | 카드의 `💡 next … [copy]` |
| 도트(픽셀) 테마 | `board.html` | localStorage `as-skin` (기본 켜짐) | 제목 줄 ▦ 버튼 |
| 가독성 수정 | `board.html` | — | 멈춘 카드를 흐리게 하지 않음, 이모지 아이콘 전용 폰트 |

서버 쪽 변경은 `board.mjs`가 제안 파일을 읽는 것 하나뿐이고, 쓰기는 없습니다. `agents.json` 형식과 CLI 동작은 바뀌지 않습니다.

## 사이드바 편집

Tasks 사이드바를 Notion 왼쪽 목록처럼 다룹니다. 모든 편집은 보는 사람 브라우저에만 저장되며, 기존 `as-task`, `as-side`와 같은 방식입니다.

| 동작 | 조작 | 저장 키 |
| --- | --- | --- |
| 순서 바꾸기 | 드래그 또는 Alt+↑/↓ (프로젝트끼리, 같은 프로젝트 안 과제끼리) | `as-order` |
| 이름 바꾸기 | 더블클릭, F2, ⋯ → Rename. 비우면 원래 이름 | `as-meta[key].name` |
| 아이콘 | ⋯ 또는 우클릭 → 이모지 24개 중 선택, Reset으로 첫 글자 복원 | `as-meta[key].icon` |
| 접기/펼치기 | 과제가 있는 프로젝트 왼쪽 ▾. 접으면 과제 대기 수가 프로젝트에 합산 | `as-meta[key].fold` |
| 숨기기 | ⋯ 또는 우클릭 → Hide. 맨 아래 `Hidden · n`에서 Show | `as-meta[key].hidden` |

- 과제를 다른 프로젝트로 옮기는 것은 막았습니다. 소속은 `agents.json`이 정합니다.
- 이름을 편집하는 동안에는 2초 주기 다시 그리기가 사이드바를 건드리지 않습니다.
- 사이드바를 접은 상태(아이콘만 보일 때)에는 편집 버튼을 숨깁니다.

## 제안 프롬프트 표시

CLI 입력창에 회색으로 뜨는 다음 프롬프트 제안을 보드 카드에도 띄웁니다. 데이터는 한 방향으로만 흐릅니다.

1. **CLI (mod `suggest-relay`)**: `prompt.suggest` 이벤트에서 제안 문구를 `~/.claude/agentsemble-suggest/<세션ID>.json`에 `{ text, at }`로 씁니다. 프롬프트를 보내면(`prompt.submit`) 빈 파일로 덮어씁니다. 두 훅 모두 `next(e)`를 그대로 돌려주므로 CLI 동작은 바뀌지 않습니다.
2. **서버 (`board.mjs`)**: `suggestOf(id, logMs)`가 그 파일을 읽어 세션 객체에 `suggest`를 붙입니다. 세션 로그가 제안보다 5초 넘게 늦으면 지난 제안으로 보고 숨깁니다(`SUGGEST_SLACK`). 자체 테스트 1개를 추가했습니다.
3. **화면 (`board.html`)**: 역할 카드와 세션 카드에 `💡 next <문구> [copy]` 한 줄을 내고, copy로 클립보드에 복사합니다. CLI로 바로 보내는 기능은 읽기 전용 원칙 때문에 넣지 않았습니다.

현재 mod는 별도 마켓플레이스(`my-mods`)에 있어 따로 설치해야 합니다. 훅 코드는 아래가 전부입니다.

```ts
import type { EngineInterface, Register } from 'claude-code'

async function fileOf($: EngineInterface) {
  const home = (await $.env.get('USERPROFILE')) ?? (await $.env.get('HOME')) ?? ''
  return `${home}/.claude/agentsemble-suggest/${await $.session.id()}.json`
}

export const register: Register = on => {
  on('prompt.suggest', async ($, e, next) => {
    const shown = await next(e)
    try { await $.fs.write(await fileOf($), JSON.stringify({ text: e.text, at: await $.clock.now() })) } catch {}
    return shown
  })
  on('prompt.submit', async ($, e, next) => {
    try { await $.fs.write(await fileOf($), '') } catch {}
    return next(e)
  }).catch(($, e, next) => next(e))
}
```

## 도트 테마

JRPG 파티 메뉴 콘셉트의 픽셀 스킨을 앤트로픽 톤으로 칠했습니다. 전부 `html.pixel` 아래 CSS 변수 재정의라서, ▦ 버튼으로 끄면 원래 화면이 그대로 나옵니다.

| 역할 | 변수 | 값 |
| --- | --- | --- |
| 페이지 바탕(6px 도트 무늬) | `--page` | `#f0eee6` 크림 |
| 카드·사이드바 | `--surface` | `#faf9f5` 아이보리 |
| 창틀·버튼 테두리 | `--frame` | `#3d3929` 먹색 |
| 본문 / 보조 / 흐린 글자 | `--text` / `--sub` / `--faint` | `#161616` / `#3f3f3f` / `#5f5f5f` |
| 포인트(선택, 리더 main) | `--calm` | `#c6613f` 클레이 |
| 완료 | `--good` | `#5f8a3a` 올리브 |
| 작업 중·대기 알림 / 바쁨 | `--live` / `--warn` | `#d9435e` / `#b8640f` |
| 타이틀 | `h1` | 노랑 `#ffd84a` + 검은 테두리·그림자 |

- 창틀은 2px 프레임과 계단식 그림자이고, 모서리는 모두 0입니다. 선택된 과제 앞에는 ▶ 커서가 깜빡이고, `prefers-reduced-motion`이면 멈춥니다.
- 폰트는 Galmuri11(한글 픽셀 폰트)을 jsdelivr `galmuri@2.40.3`에서 불러옵니다. 오프라인이면 시스템 monospace로 대체됩니다.
- 멈춘 카드는 흐리게 하지 않고 라벨로만 알립니다. 흐리게 하면 도트 폰트 글자가 읽히지 않았습니다.
- 사이드바 이모지 아이콘은 컬러 이모지 폰트(`Segoe UI Emoji` 등)로 그리고 도트 배경을 씌우지 않습니다. 픽셀 폰트의 흑백 이모지가 깨져 보이던 문제를 막습니다.

## 반영할 때 검토할 점

- [ ] **사이드바 저장 key**: 지금은 `--also` 순서 기준 인덱스(`0:`, `1:KORU sim`)입니다. 보드를 다른 인자 순서로 띄우면 이름·아이콘·순서가 다른 항목에 붙습니다. upstream에서는 저장소 경로 기반 key를 권합니다.
- [ ] **suggest-relay 훅 위치**: 별도 mod 대신 agentsemble 플러그인의 hooks 모듈로 옮기면 따로 설치할 필요가 없습니다.
- [ ] **폰트 외부 로드**: Galmuri11을 jsdelivr에서 불러오는 것이 보드의 첫 외부 리소스입니다. 사내망·오프라인을 고려하면 폰트 파일을 플러그인에 포함해 배포하는 쪽이 낫습니다(SIL OFL).
- [ ] **도트 테마 기본값**: 지금은 기본 켜짐입니다. upstream에서는 기본 꺼짐 + ▦ 버튼으로 켜는 쪽도 검토해 주세요.
- [ ] **터치 환경**: 휴대폰에서는 드래그 정렬이 되지 않고 ⋯ 메뉴만 동작합니다.
- [ ] **데스크톱 알림 안내**: 포트가 다르면 브라우저가 다른 사이트로 봐서 8740에서 허용한 알림이 8741에는 적용되지 않습니다. Edge는 조용한 요청(주소창 종 아이콘)으로 묻기 때문에, 버튼을 눌러도 반응이 없는 것처럼 보입니다. 벨 패널에 한 줄 안내를 넣는 것을 제안합니다.
